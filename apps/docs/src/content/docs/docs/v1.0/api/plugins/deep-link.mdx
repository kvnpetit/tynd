# `deep-link`

`@tynd/plugin-deep-link` enables the host `deep-link` API and exposes its typed client. The API itself is documented on the [`deepLink`](/docs/v1.0/api/os/deepLink) page.

## Install

```bash
tynd add deep-link
```

```ts
import { deepLink } from "@tynd/plugin-deep-link/client";
```

Declaring the plugin compiles the matching `api-deep-link` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-deep-link` and list it in `plugins` in `tynd.config.ts`.
