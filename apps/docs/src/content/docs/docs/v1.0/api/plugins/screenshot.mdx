# `screenshot`

`@tynd/plugin-screenshot` enables the host `screenshot` API and exposes its typed client. The API itself is documented on the [`screenshot`](/docs/v1.0/api/os/screenshot) page.

## Install

```bash
tynd add screenshot
```

```ts
import { screenshot } from "@tynd/plugin-screenshot/client";
```

Declaring the plugin compiles the matching `api-screenshot` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-screenshot` and list it in `plugins` in `tynd.config.ts`.
