# `tts`

`@tynd/plugin-tts` wraps the cross-platform `tts` crate: SAPI 5 on Windows, `AVSpeechSynthesizer` on macOS, `speech-dispatcher` (or espeak) on Linux.

## Install

```bash
tynd add tts
```

or `bun add @tynd/plugin-tts` and list it in `tynd.config.ts`:

```ts title="tynd.config.ts"
export default {
  plugins: ["@tynd/plugin-tts"],
}
```

`tynd dev` and `tynd build` link the plugin's Rust crate into the app host they compile.

## Use

```ts
import { tts } from "@tynd/plugin-tts";

const voices = await tts.listVoices();
await tts.speak("Hello from Tynd!", {
  voice: voices.find((v) => v.language.startsWith("en"))?.id,
  rate: 1.0,
  pitch: 1.0,
  volume: 0.8,
});

while (await tts.isSpeaking()) await new Promise((r) => setTimeout(r, 100));
await tts.stop();
```

## API

| Method | Purpose |
|---|---|
| `tts.listVoices()` | Installed voices on the host |
| `tts.speak(text, opts?)` | Queue an utterance; resolves on hand-off, not on completion |
| `tts.stop()` | Cancel speech; safe to call when idle |
| `tts.isSpeaking()` | Whether the synthesizer is busy |

## Pitfalls

- `speak` returns before the speech ends; poll `isSpeaking()` to wait. Calls queue behind speech in progress; call `stop()` first to interrupt instead.
- `rate` and `pitch` take `0` to `2` and `volume` takes `0` to `1`, on every platform. `1.0` for `rate` / `pitch` is the engine's normal value, `0` is its minimum and `2` / `1` its maximum. Values outside the range are clamped; non-finite values (`NaN`, `Infinity`) are rejected. Text is limited to 64 KiB per call.
- Rendering text to a WAV file is not exposed.
- On Linux the voices depend on `speech-dispatcher` or espeak being installed.
