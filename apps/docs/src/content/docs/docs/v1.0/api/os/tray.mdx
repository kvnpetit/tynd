# `tray`

Install the required plugin:

```bash
tynd add tray
```

```ts
import { tray } from "@tynd/plugin-tray/client";
```

The tray icon + menu are declared in `app.start({ tray: … })` on the backend. This module lets the frontend (or backend) subscribe to user interactions.

## Declare the tray

```ts title="backend/main.ts"
app.start({
  tray: {
    icon:    import.meta.dir + "/assets/tray.png",
    tooltip: "My App",
    menu: [
      { label: "Show",       id: "show" },
      { label: "Preferences", id: "prefs" },
      { type: "separator" },
      { label: "Quit",       id: "quit" },
    ],
  },
  // ...
});
```

## Click handlers

```ts
tray.onClick(() => tyndWindow.show());
tray.onRightClick(() => { /* context menu is native; this fires alongside */ });
tray.onDoubleClick(() => tyndWindow.show());

// Mouse enter / move / leave the tray region (physical pixels).
tray.onEnter(({ x, y }) => previewNearTray(x, y));
tray.onMove(({ x, y }) => updatePreviewPos(x, y));
tray.onLeave(() => dismissPreview());
```

Each returns an `unsubscribe()` function.

## Runtime mutation

```ts
await tray.setIcon("/abs/new-icon.png");
await tray.setTooltip("3 unread");
await tray.setTitle("42");                // macOS menu bar text only
await tray.setVisible(false);
await tray.setIconAsTemplate(true);       // macOS — auto-adapt to light/dark menu bar
await tray.setMenu([
  { id: "open", label: "Open" },
  { type: "separator" },
  { id: "quit", label: "Quit", role: "quit" },
]);
```

## Mutate single items

Change one item by `id` without rebuilding the menu with `setMenu`. Each rejects if the `id` was never registered.

```ts
await tray.setItemEnabled("sync", false);
await tray.setItemLabel("sync", "Syncing...");
await tray.setItemChecked("autostart", true);   // checkbox / radio items only
await tray.setItemVisible("debug", false);      // detached; re-inserted near its old position
```

| Method | Signature |
| --- | --- |
| `setItemEnabled` | `(id: string, enabled: boolean): Promise<void>` |
| `setItemLabel` | `(id: string, label: string): Promise<void>` |
| `setItemChecked` | `(id: string, checked: boolean): Promise<void>` (errors on non-checkbox/radio items) |
| `setItemVisible` | `(id: string, visible: boolean): Promise<void>` |

The same four exist on [`menu`](/docs/v1.0/api/os/menu) for the menu bar.

## Menu item handlers

```ts
tray.onMenu("show",  () => tyndWindow.show());
tray.onMenu("prefs", () => openSettings());
tray.onMenu("quit",  () => app.exit(0));
```

The `id` matches the `id` field you set on the tray menu item.

## Notes

- Tray events are broadcast — a handler registered in any window (or in the backend) fires on matching events.
- Platform quirks: macOS fires double-click only if `onClick` doesn't handle it; Windows fires both. Guard on `Date.now()` deltas if you need strict discrimination.
- Dynamic icon + tooltip + menu are supported via `tray.set*`; mouse enter/move/leave events fire on every OS.
- Requires `@tynd/plugin-tray` in your dependencies and in `plugins` (`tynd add tray`), which compiles the tray API into the app host. Without it, `tray.*` calls reject and a configured `tray` stops app startup, both with an error naming `@tynd/plugin-tray`. Calls also reject when no `tray` is configured, and are subject to the `tray:<method>` [ACL rules](/docs/v1.0/concepts/security).
