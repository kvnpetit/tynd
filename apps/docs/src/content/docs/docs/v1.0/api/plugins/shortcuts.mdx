# `shortcuts`

`@tynd/plugin-shortcuts` enables the host `shortcuts` API and exposes its typed client. The API itself is documented on the [`shortcuts`](/docs/v1.0/api/os/shortcuts) page.

## Install

```bash
tynd add shortcuts
```

```ts
import { shortcuts } from "@tynd/plugin-shortcuts/client";
```

Declaring the plugin compiles the matching `api-shortcuts` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-shortcuts` and list it in `plugins` in `tynd.config.ts`.
