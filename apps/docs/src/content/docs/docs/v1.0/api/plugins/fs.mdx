# `fs`

`@tynd/plugin-fs` enables the host `fs` API and exposes its typed client. The API itself is documented on the [`fs`](/docs/v1.0/api/os/fs) page.

## Install

```bash
tynd add fs
```

```ts
import { fs } from "@tynd/plugin-fs/client";
```

Declaring the plugin compiles the matching `api-fs` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-fs` and list it in `plugins` in `tynd.config.ts`.
