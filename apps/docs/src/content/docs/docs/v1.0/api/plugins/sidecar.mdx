# `sidecar`

`@tynd/plugin-sidecar` enables the host `sidecar` API and exposes its typed client. The API itself is documented on the [`sidecar`](/docs/v1.0/api/os/sidecar) page.

## Install

```bash
tynd add sidecar
```

```ts
import { sidecar } from "@tynd/plugin-sidecar/client";
```

Declaring the plugin compiles the matching `api-sidecar` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-sidecar` and list it in `plugins` in `tynd.config.ts`.
