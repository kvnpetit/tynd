# `clipboard`

Install the required plugin:

```bash
tynd add clipboard
```

```ts
import { clipboard } from "@tynd/plugin-clipboard/client";
```

## Text

```ts
const text = await clipboard.readText();
await clipboard.writeText("Hello!");
```

## HTML

```ts
await clipboard.writeHtml(`<p><b>Hello</b> world</p>`);
await clipboard.writeHtml(`<p>rich</p>`, "rich");   // optional plain-text fallback

const html = await clipboard.readHtml();   // string | null
```

`writeHtml` sets both `text/html` and (optionally) a plain-text variant.
`readHtml` returns the native HTML representation on Windows, macOS, X11, and
Wayland, or `null` when none exists.

## Files

```ts
const paths = await clipboard.readFiles(); // string[]
await clipboard.writeFiles([
  "/home/user/Documents/report.pdf",
  "/home/user/Pictures/diagram.png",
]);
```

File references use the OS clipboard's native file-list format. `readFiles`
returns `[]` when no file list exists. `writeFiles` requires 1–1024 non-empty,
NUL-free paths; it copies references, not file contents.

## Image

```ts
interface ClipboardImage {
  png:    string;   // base64-encoded PNG bytes
  width:  number;
  height: number;
}

const img = await clipboard.readImage();   // ClipboardImage | null
if (img) {
  // Decode: atob(img.png) → binary string → Uint8Array → <img> src
  const bin = atob(img.png);
  const bytes = new Uint8Array(bin.length);
  for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
  const url = URL.createObjectURL(new Blob([bytes], { type: "image/png" }));
  document.querySelector("img")!.src = url;
}

await clipboard.writeImage(pngBase64);   // string — base64 PNG
```

<Aside type="note">
  **Image format is base64 PNG, not RGBA.** `writeImage` takes a base64-encoded PNG string; `readImage` returns `{ png, width, height }` where `png` is base64. Convert to/from `Uint8Array` via `atob`/`btoa` or use a Blob.
</Aside>

## Clear

```ts
await clipboard.clear();
```

## Change monitoring

Polled cross-OS — no native event API exists without heavy platform code. Default poll interval 200 ms; pass `{ intervalMs }` as the second argument to change it (minimum 50). The first subscriber's interval applies to every subscriber. `clipboard:change` events carry the clipboard text, so they reach app-local webviews only, never a webview showing remote content.

```ts
const unsub = await clipboard.onChange(({ text }) => updateSnippetPreview(text));
// later: await unsub();
```

## Notes

- Clipboard state is shared with the rest of the OS — writes replace whatever the user had copied.
- On Wayland, clipboard semantics vary by compositor; a few (without `wlr_data_control`) may return empty.
