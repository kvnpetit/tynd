# `single-instance`

`@tynd/plugin-single-instance` enables the host `single-instance` API and exposes its typed client. The API itself is documented on the [`single-instance`](/docs/v1.0/api/os/single-instance) page.

## Install

```bash
tynd add single-instance
```

```ts
import { singleInstance } from "@tynd/plugin-single-instance/client";
```

Declaring the plugin compiles the matching `api-single-instance` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-single-instance` and list it in `plugins` in `tynd.config.ts`. Without it, calls reject with an error naming `@tynd/plugin-single-instance`.
