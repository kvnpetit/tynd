# `shell`

`@tynd/plugin-shell` enables the host `shell` API and exposes its typed client. The API itself is documented on the [`shell`](/docs/v1.0/api/os/shell) page.

## Install

```bash
tynd add shell
```

```ts
import { shell } from "@tynd/plugin-shell/client";
```

Declaring the plugin compiles the matching `api-shell` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-shell` and list it in `plugins` in `tynd.config.ts`. Without it, calls reject with an error naming `@tynd/plugin-shell`.
