# `http`

`@tynd/plugin-http` enables the host `http` API and exposes its typed client. The API itself is documented on the [`http`](/docs/v1.0/api/os/http) page.

## Install

```bash
tynd add http
```

```ts
import { http } from "@tynd/plugin-http/client";
```

Declaring the plugin compiles the matching `api-http` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-http` and list it in `plugins` in `tynd.config.ts`.
