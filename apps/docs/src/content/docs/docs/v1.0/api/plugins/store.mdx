# `store`

`@tynd/plugin-store` enables the host `store` API and exposes its typed client. The API itself is documented on the [`store`](/docs/v1.0/api/os/store) page.

## Install

```bash
tynd add store
```

```ts
import { createStore } from "@tynd/plugin-store/client";
```

Declaring the plugin compiles the matching `api-store` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-store` and list it in `plugins` in `tynd.config.ts`. Without it, calls reject with an error naming `@tynd/plugin-store`.
