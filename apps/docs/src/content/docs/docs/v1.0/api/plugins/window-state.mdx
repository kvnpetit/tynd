# `window-state`

`@tynd/plugin-window-state` enables the host `window-state` API and exposes its typed client. The API itself is documented on the [`windowState`](/docs/v1.0/api/os/windowState) page.

## Install

```bash
tynd add window-state
```

```ts
import { windowState } from "@tynd/plugin-window-state/client";
```

Declaring the plugin compiles the matching `api-window-state` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-window-state` and list it in `plugins` in `tynd.config.ts`.
