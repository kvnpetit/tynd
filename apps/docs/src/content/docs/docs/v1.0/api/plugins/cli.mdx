# `cli`

`@tynd/plugin-cli` enables the host `cli` API and exposes its typed client. The API itself is documented on the [`cli`](/docs/v1.0/api/os/cli) page.

## Install

```bash
tynd add cli
```

```ts
import { cli } from "@tynd/plugin-cli/client";
```

Declaring the plugin compiles the matching `api-cli` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-cli` and list it in `plugins` in `tynd.config.ts`. Without it, calls reject with an error naming `@tynd/plugin-cli`.
