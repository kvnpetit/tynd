# `system-stats`

`@tynd/plugin-system-stats` enables the host `system-stats` API and exposes its typed client. The API itself is documented on the [`systemStats`](/docs/v1.0/api/os/systemStats) page.

## Install

```bash
tynd add system-stats
```

```ts
import { systemStats } from "@tynd/plugin-system-stats/client";
```

Declaring the plugin compiles the matching `api-system-stats` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-system-stats` and list it in `plugins` in `tynd.config.ts`.
