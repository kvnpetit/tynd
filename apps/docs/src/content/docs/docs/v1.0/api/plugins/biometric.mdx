# `biometric`

`@tynd/plugin-biometric` enables the host `biometric` API and exposes its typed client. The API itself is documented on the [`biometric`](/docs/v1.0/api/os/biometric) page.

## Install

```bash
tynd add biometric
```

```ts
import { biometric } from "@tynd/plugin-biometric/client";
```

Declaring the plugin compiles the matching `api-biometric` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-biometric` and list it in `plugins` in `tynd.config.ts`.
