# `keys`

`@tynd/plugin-keys` enables the host `keys` API and exposes its typed client. The API itself is documented on the [`keys`](/docs/v1.0/api/os/keys) page.

## Install

```bash
tynd add keys
```

```ts
import { keys } from "@tynd/plugin-keys/client";
```

Declaring the plugin compiles the matching `api-keys` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-keys` and list it in `plugins` in `tynd.config.ts`. Without it, calls reject with an error naming `@tynd/plugin-keys`.
