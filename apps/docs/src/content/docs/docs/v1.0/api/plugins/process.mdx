# `process`

`@tynd/plugin-process` enables the host `process` API and exposes its typed client. The API itself is documented on the [`process`](/docs/v1.0/api/os/process) page.

## Install

```bash
tynd add process
```

```ts
import { process } from "@tynd/plugin-process/client";
```

Declaring the plugin compiles the matching `api-process` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-process` and list it in `plugins` in `tynd.config.ts`.

## Security

`process` is the broadest host capability. Grant only the commands you need in your [capabilities](/docs/v1.0/concepts/security).
