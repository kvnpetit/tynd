# `notification`

`@tynd/plugin-notification` enables the host `notification` API and exposes its typed client. The API itself is documented on the [`notification`](/docs/v1.0/api/os/notification) page.

## Install

```bash
tynd add notification
```

```ts
import { notification } from "@tynd/plugin-notification/client";
```

Declaring the plugin compiles the matching `api-notification` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-notification` and list it in `plugins` in `tynd.config.ts`.
