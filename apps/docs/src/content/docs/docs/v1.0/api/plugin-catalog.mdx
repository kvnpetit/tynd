# Plugin Catalog

The source of truth is [`plugins/catalog.json`](https://github.com/kvnpetit/tynd/blob/main/plugins/catalog.json).
Its ids and aliases are compiled into the CLI: `tynd add <id>` and `tynd add <alias>` resolve to the package listed here.

## Official Plugins

Every plugin in the catalog is an official plugin, maintained by Tynd.

### Host-backed Plugins

## Community Plugins

Plugins made by anyone else are community plugins. They are not in the catalog; add them by package name:

```bash
tynd add @scope/plugin
```

A community plugin's `package.json` has a `tynd` block without `kind` (`kind` is reserved for `"host"` and `"standalone"`). [`tynd plugin list`](/docs/v1.0/cli/plugin/list) prints each declared plugin as `native` or `js`; with `--json` it also reports its `family`: `host`, `standalone` or `community`.
