# `theme`

`@tynd/plugin-theme` enables the host `theme` API and exposes its typed client. The API itself is documented on the [`theme`](/docs/v1.0/api/os/theme) page.

## Install

```bash
tynd add theme
```

```ts
import { theme } from "@tynd/plugin-theme/client";
```

Declaring the plugin compiles the matching `api-theme` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-theme` and list it in `plugins` in `tynd.config.ts`. Without it, calls reject with an error naming `@tynd/plugin-theme`.
