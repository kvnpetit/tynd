# `dialog`

`@tynd/plugin-dialog` enables the host `dialog` API and exposes its typed client. The API itself is documented on the [`dialog`](/docs/v1.0/api/os/dialog) page.

## Install

```bash
tynd add dialog
```

```ts
import { dialog } from "@tynd/plugin-dialog/client";
```

Declaring the plugin compiles the matching `api-dialog` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-dialog` and list it in `plugins` in `tynd.config.ts`. Without it, calls reject with an error naming `@tynd/plugin-dialog`.
