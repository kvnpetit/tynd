# `network`

`@tynd/plugin-network` enables the host `network` API and exposes its typed client. The API itself is documented on the [`network`](/docs/v1.0/api/os/network) page.

## Install

```bash
tynd add network
```

```ts
import { network } from "@tynd/plugin-network/client";
```

Declaring the plugin compiles the matching `api-network` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-network` and list it in `plugins` in `tynd.config.ts`.
