# `autolaunch`

`@tynd/plugin-autolaunch` enables the host `autolaunch` API and exposes its typed client. The API itself is documented on the [`autolaunch`](/docs/v1.0/api/os/autolaunch) page.

## Install

```bash
tynd add autolaunch
```

```ts
import { autolaunch } from "@tynd/plugin-autolaunch/client";
```

Declaring the plugin compiles the matching `api-autolaunch` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-autolaunch` and list it in `plugins` in `tynd.config.ts`.
