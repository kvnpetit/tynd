# `vault`

`@tynd/plugin-vault` enables the host `vault` API and exposes its typed client. The API itself is documented on the [`vault`](/docs/v1.0/api/os/vault) page.

## Install

```bash
tynd add vault
```

```ts
import { vault } from "@tynd/plugin-vault/client";
```

Declaring the plugin compiles the matching `api-vault` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-vault` and list it in `plugins` in `tynd.config.ts`.
