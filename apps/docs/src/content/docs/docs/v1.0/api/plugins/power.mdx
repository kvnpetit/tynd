# `power`

`@tynd/plugin-power` enables the host `power` API and exposes its typed client. The API itself is documented on the [`power`](/docs/v1.0/api/os/power) page.

## Install

```bash
tynd add power
```

```ts
import { power } from "@tynd/plugin-power/client";
```

Declaring the plugin compiles the matching `api-power` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-power` and list it in `plugins` in `tynd.config.ts`.
