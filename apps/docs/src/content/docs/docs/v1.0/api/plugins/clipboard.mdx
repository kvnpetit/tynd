# `clipboard`

`@tynd/plugin-clipboard` enables the host `clipboard` API and exposes its typed client. The API itself is documented on the [`clipboard`](/docs/v1.0/api/os/clipboard) page.

## Install

```bash
tynd add clipboard
```

```ts
import { clipboard } from "@tynd/plugin-clipboard/client";
```

Declaring the plugin compiles the matching `api-clipboard` Cargo feature into the app host on the next `tynd dev` or `tynd build`. Or by hand: `bun add @tynd/plugin-clipboard` and list it in `plugins` in `tynd.config.ts`. Without it, calls reject with an error naming `@tynd/plugin-clipboard`.
