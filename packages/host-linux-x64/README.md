# @tynd/host-linux-x64

Internal platform package — do not install directly.

Installed automatically as an `optionalDependency` of [`@tynd/host`](https://www.npmjs.com/package/@tynd/host) when the host platform matches `linux-x64`.

Ships pre-built `tynd-full` + `tynd-lite` binaries for Linux x64.
