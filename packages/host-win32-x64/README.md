# @tynd/host-win32-x64

Internal platform package — do not install directly.

Installed automatically as an `optionalDependency` of [`@tynd/host`](https://www.npmjs.com/package/@tynd/host) when the host platform matches `win32-x64`.

Ships pre-built `tynd-full.exe` + `tynd-lite.exe` binaries for Windows x64.
