# @tynd/host-linux-arm64

Internal platform package — do not install directly.

Installed automatically as an `optionalDependency` of [`@tynd/host`](https://www.npmjs.com/package/@tynd/host) when the host platform matches `linux-arm64`.

Ships pre-built `tynd-full` + `tynd-lite` binaries for Linux ARM64.
